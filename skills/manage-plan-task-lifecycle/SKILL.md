# Manage Plan and Task Lifecycle

Create planned work with stable identity, objective, dependencies, evidence, and completion criteria. Increase progress only after an exit gate passes. Before completion, verify required work, tests, evidence, dates, archive destination, and affected links. Move completed work intact to the archive and remove its active duplicate. Reopening is explicit and restores only one authoritative active note.
